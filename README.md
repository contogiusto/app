# Perfe

Webapp per la gestione di ordini e pagamenti nei ristoranti: il cliente accede dal QR del tavolo, il cameriere apre la sessione e inserisce gli ordini, il ristoratore gestisce menu e tavoli.

**Stack:** React + TypeScript (Vite) · FastAPI · PostgreSQL (Neon) · deploy su Vercel.

Per sviluppare vedi [CLAUDE.md](CLAUDE.md) (comandi), [CONTRIBUTING.md](CONTRIBUTING.md) (flusso feature branch → PR → main) e [docs/domain.md](docs/domain.md) (dominio).
